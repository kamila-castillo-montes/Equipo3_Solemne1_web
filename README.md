## Descripción del sitio
Este sitio web es una plataforma de turismo local pensada para mostrar las actividades, alojamientos y paisajes de la zona cordillerana. La idea principal es que los visitantes puedan revisar diferentes panoramas al aire libre, ver lugares para comer o quedarse, y enviar un formulario para cotizar o reservar sus salidas

## Tecnologías utilizadas
* HTML5 para toda la estructura de las páginas.
* CSS3 para los colores, fuentes, formas y adaptar la pantalla a celulares.
* Bootstrap 5 para el diseño de las tarjetas, botones y orden de las columnas.

## Instrucciones para ver el sitio
1. Descargar o clonar la carpeta completa del proyecto.
2. Asegurarse de que las fotos estén guardadas en la carpeta llamada "img" y la hoja de estilos en la carpeta "css", si no probablemnete se generará un error
3. Abrir el archivo `index.html` en cualquier navegador web
4. Navegar por los enlaces del menú superior o los botones de la página de inicio para recorrer la página de panoramas, alojamientos y el formulario de contacto.
